## A. Carry-genopfyldning: regelmodeller (specificeret før data)

**Population:** hver `lane.started` for en carry-funktion (family fcarry; ikke scanner/HL). Evaluérbar hvis der
findes `pricing_constraint/2 predicted_funding` for de indgåede mønter i de 72 t før start (data fra 10-20 09:33 UTC);
ellers rapporteres banen som ikke-evaluérbar.

**Informationer ved start t0 (kun fortid):** indgåede mønter = de mønter banen fik fills i inden for 1 t efter t0
(det lab'et selv vidste via 11b ved t0); G = indgangens bruttoeksponering (begge ben) fra disse fills; f̂ = for hver
mønt middel af predicted_funding (pr. 8 t) over 72 t før t0, derefter lige vægt over mønterne; APR = f̂ × 3 × 365.
**Omkostningsmodel (registreret):** pr. ben pr. side c = taker 0,001 + slippage 0,0002 = 0,0012 af notional (bogens
halve spread kommer oveni; ikke modelleret ex ante). Round-trip på G: 2 × c × G. Funding tjenes på perp-benet G/2.
**Forventet netto over H = 14 d:** E = f̂ × 3 × 14 × G/2 − 2 × c × G.
**Break-even-APR (kun konstanter):** kun gebyrer: 2×0,001×2×365/14 = **10,4 %**; med slippage: 2×0,0012×2×365/14 =
**12,5 %**.

| Model | Regel ved t0 |
|---|---|
| M0 status quo | start når varianten holder noget (alle observerede starter) |
| M1 højere tærskel | start kun hvis variantens egen `enter_apr` ≥ 10,4 % (kun gebyr-break-even); ellers er varianten ikke kandidat |
| M2(k) forventet samlet netto | start kun hvis f̂ × 3 × 14 × G/2 ≥ (1 + k) × 2 × c × G; k ∈ {0; 0,5; 1}; primær k = 0,5 |
| M3 regime-pause | ingen ny carry-start, mens de 2 senest stoppede carry-baner (stoppet før t0) har netto < 0 efter afvikling OG seneste `funding_median` × 3 × 365 < 12,5 %; ophæves når en af delene ikke længere gælder |

**Mål pr. model (deskriptivt):** antal starter taget/undgået; samlet realiseret netto for tagne og undgåede baner
(stoppet: endeligt netto inkl. afvikling; aktiv: nuværende netto − forudsagt afvikling 0,001 × nuværende brutto,
markeret foreløbig); "fejlagtigt undgået" = undgået bane med netto > 0. **Robusthed:** f̂ som seneste observation i
stedet for 72 t-middel; uden den største taber; k-følsomhed (sikkerhedsmargin) for M2.
**Fortolkning fastsat nu:** n er lille (forventet ≲ 15) og alle kendte udfald er negative, så en model der blot blokerer
alt vil se bedst ud. Ingen model erklæres "bedst" alene på undgået tab; den skal også (i) bruge information der findes
ved t0, (ii) have færrest fejlagtigt undgåede, (iii) kunne åbne igen når regimet skifter (M3 og M2 kan, en permanent
højere tærskel kun hvis funding stiger over den). Ingen p-værdier; intet afgøres.

**Afviklingsgebyr før indgang:** forudsigelse = 0,001 × G (planlagt indgangsbrutto) mod faktisk afviklingsgebyr for
hver stoppet carry-bane; rapportér forhold faktisk/forudsagt, median og spænd. "Pålideligt nok" fastsat nu: alle
forhold inden for [0,7; 1,3].
